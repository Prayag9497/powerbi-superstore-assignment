# Power BI Assignment – Superstore & Finance Dataset

This repository contains my Power BI assignment that demonstrates skills in DAX, data modeling, visual analytics, conditional formatting, and dashboard creation using **Superstore** and **Finance** datasets.

## 📁 Files

- `PowerBI_Assignment.pbix` – Main Power BI file with all visuals
- `Dataset/Superstore.csv` – Sales and product dataset
- `Dataset/Finance.csv` – Financial time-series dataset
- `Screenshots/dashboard-preview.png` – Preview image of final dashboard

## ✅ Tasks Covered

| Task | Description | Dataset |
|------|-------------|---------|
| Q1 | What is Power BI? | – |
| Q2 | This Year vs Last Year Sales (with Growth %) | Superstore |
| Q3 | Waterfall Chart - Category-wise Analysis | Superstore |
| Q4 | Hierarchy (Country → Postal Code) | Superstore |
| Q5 | Bookmarks by Year, Quarter, Month | Finance |
| Q6 | Drill Through - Region-wise Profit | Superstore |
| Q7 | Conditional Formatting Table | Superstore |
| Q8 | Finance Dashboard | Finance |
